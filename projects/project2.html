To-Do App

Streamlined task management and daily workflow organizer.

About the Project

The To-Do App is a task management application designed to help users organize their daily schedules, manage tasks, and boost productivity.

Purpose

The project provides a clear, simple way to create, manage, prioritize, and complete tasks without unnecessary clutter or distraction.

Key Features

  • Instant task creation with intuitive keyboard shortcuts.
  • Mark tasks as completed with strikethrough visual indicators.
  • Filters for Active, Completed, and All tasks.
  • Persistent task storage using browser LocalStorage.

Technologies Used

HTML5 CSS3 JavaScript
