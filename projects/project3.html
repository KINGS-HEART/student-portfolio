Wine E-Commerce App

A curated wine store showcase with product catalog, cart management, and interactive UI.

About the Project

The Wine E-Commerce App is a modern web application designed to provide customers with an elegant browsing and shopping experience for premium wines and beverages.

Purpose

The purpose of this project is to create an accessible, responsive, and intuitive digital storefront that allows customers to explore product details, filter vintages, and manage items in their shopping cart smoothly.

Key Features

  • Catalog showcase displaying premium wine collections with ratings and vintage details.
  • Dynamic product filtering by type, region, and price tier.
  • Interactive cart drawer with real-time total calculations and quantity adjustments.
  • Clean, responsive layout optimized across mobile, tablet, and desktop devices.

Technologies Used

HTML5 CSS3 JavaScript
