Expense Tracker

Personal expense monitoring and financial accounting web tool.

About the Project

The Expense Tracker is a web application designed to help users record, categorize, and monitor their day-to-day expenses.

Purpose

The purpose of the project is to make it easier for users to keep track of their personal spending habits, monitor cash flow, and maintain financial discipline.

Key Features

  • Simple input form for entering amount, category, and date of transactions.
  • Real-time running balance and itemized list of recent expenditures.
  • Delete and edit capability for fast expense corrections.
  • Visual expense categories for quick at-a-glance financial insights.

Technologies Used

HTML5 CSS3 JavaScript
